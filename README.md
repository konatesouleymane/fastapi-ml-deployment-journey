# FastAPI ML Deployment Journey

A hands-on learning journey into deploying Machine Learning models using FastAPI.

##  Objective

Learn how to integrate, serve, and deploy Machine Learning models through REST APIs using FastAPI.

##  Learning Goals

- Understand how trained ML models are stored and loaded.
- Integrate Scikit-learn models into FastAPI.
- Build prediction endpoints.
- Validate input data using Pydantic.
- Handle API errors.
- Test APIs using Swagger UI.
- Containerize applications using Docker.

##  Technologies

- Python
- FastAPI
- Scikit-learn
- Joblib
- Pydantic
- Docker
- Git & GitHub
